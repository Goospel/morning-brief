# T-004 · 형식 테스트가 통과해도 LLM 요약의 내용은 틀릴 수 있다

- **증상**: 파이프라인이 정상 동작한 채로 **오보가 만들어졌다**. 기사 133(연합뉴스)의 원문 제목은

  ```
  與 "미래대응기금으로 재정 안정"…국힘 "혈세 맘대로 쓸 꼼수"(종합)
  ```

  여당(與)이 찬성, 국민의힘이 비판이다. 그런데 DB에 들어간 요약은 정확히 반대였다:

  ```
  …야당은 이를 재정을 안정적으로 운영하기 위한 조치로 평가하고 여당은 국민 세금을
  자의적으로 사용하는 꼼수라고 비판하며 이견을 드러냈다.
  ```

  JSON은 멀쩡히 파싱됐고 태그(`economy,finance,policy`)도 고정 어휘 안이었다. `npm test` 37개 전부 통과. **어디에도 빨간불이 없었다.** 브리핑에 실려 나갔다면 그대로 오보다.

  같은 실행에서 스포츠 기사 2건(131 축구, 132 야구)이 `culture` 태그를 받아 브리핑 6칸 중 2칸을 차지한 것도 함께 드러났다 — 고정 어휘에 `sports`가 없어 모델이 가장 가까운 칸에 밀어 넣은 것이다. 이쪽도 형식 검사는 통과다(`culture`는 어휘 안이니까).

- **원인**: 두 겹이다.
  1. 표면 원인 — `raw_excerpt`가 `"…미래대응기금을 신설하기로 한 것..."`에서 잘려 **여야의 입장이 제목에만 있었다.** 모델은 발췌만으로는 누가 어느 편인지 알 수 없는 상태에서 제목의 `與`를 해석하려다 짝을 뒤집었다. 한자 약칭(`與`/`野`)은 흔한 표기지만 모델이 「여당」·「야당」으로 바꿔 쓰는 순간 짝이 어긋날 여지가 생긴다.
  2. **진짜 원인 — 내용의 참거짓을 보는 계측기가 애초에 없다.** 테스트 37개는 전부 **형식** 검사다: JSON이 파싱되는가(`parseSummary`), 태그가 고정 어휘 안인가, 빈 요약이 아닌가. 이것들은 *모델이 규격에 맞는 것을 뱉었는가*를 잴 뿐 *뱉은 내용이 사실인가*는 건드리지 않는다. 그리고 후자는 자동화가 어렵다 — 판정하려면 원문을 읽고 사실 대조를 해야 하는데, 그걸 또 다른 LLM에 맡기면 같은 실패 모드를 물려받는다. 요약 파이프라인은 **정상 동작했다.** 그래서 더 위험하다: 고장 난 파이프라인은 시끄럽지만, 정상 동작하며 틀린 내용을 만드는 파이프라인은 조용하다.

- **해결**: 계측기를 새로 만드는 대신 **입력 쪽(프롬프트 가드)을 조이고, 실제 기사로 눈 검증**했다. 모델은 Haiku 4.5 그대로 뒀다.

  `summarize-submit`의 시스템 프롬프트 규칙에 두 줄 추가:

  ```
  - 원문에 없는 사실을 지어내지 않는다. 특히 누가 무엇을 말했는지(발언 주체), 찬반 입장,
    인과 관계는 원문에 명시된 대로만 쓴다. 원문이 짧아 알 수 없으면 그 부분을 요약에서
    빼고, 추측으로 채우지 않는다.
  - 제목에 서로 다른 주체의 발언이 나란히 나오면 각 발언을 원래 주체에 정확히 붙인다.
    주체를 다른 표현으로 바꾸지 말고 원문 표기를 그대로 쓴다 — 예를 들어 「與」를
    「여당」이나 「야당」으로 해석해 옮기지 않는다.
  ```

  그리고 `TOPICS`에 `sports`를 추가했다(12개 → 13개). 단 `profile_rules` 시드에는 넣지 않는다 — 스포츠는 호불호가 갈려 나이·직업으로 미는 것이 맞지 않고, 온보딩에서 직접 고른 사람에게만 가야 한다.

  **같은 기사 3건을 실제로 다시 요약해 판정이 뒤집히는 것을 확인했다.** 비용은 미요약 319건을 임시 마커(`__TEMP_EXCLUDE__`)로 막아 3건으로 좁혔다(검증 후 0건으로 되돌림 — 마커가 남으면 다음 실행에서 가짜 요약이 브리핑에 실린다).

  ```
  133 | {economy,policy} | 정부가 반도체 호황으로 걷힌 추가 세수를 활용해 미래대응기금을
        신설하기로 한 것을 두고 여야가 대립하고 있다. 與는 이를 재정 안정을 위한 조치라고
        평가하는 반면, 국힘은 국민 세금을 정부의 판단에 따라 맘대로 쓰는 꼼수라고 비판하고 있다.
  131 | {sports} | …이승우 선수와 울산의 김현석 감독이 선수 교체 문제로 거친 언쟁을…
  132 | {sports} | …안우진이 투수판 위치 변경 후 슬라이더가 회복되면서…
  ```

  **판정: 3건 모두 통과.** 133은 짝이 바로 잡혔고(`與`=재정 안정 / `국힘`=꼼수), 가드가 요구한 대로 **원문 표기 `與`·`국힘`을 그대로 유지**해 「여당/야당」 변환 자체를 하지 않았다 — 뒤집힐 여지가 생기는 지점을 아예 밟지 않은 것이다. 131·132는 `sports` 태그를 받았다. 기존 요약 2건(4, 251)은 건드리지 않아 그대로다.

  테스트 쪽에서는 `sports`가 어휘로 들어오면서 **기존 테스트 2건이 깨졌다** — 둘 다 `sports`를 「어휘 밖 태그」의 예시로 쓰고 있었기 때문이다. 검증 의도는 그대로 두고 예시 태그만 어휘에 없을 값(`weather`·`gossip`)으로 바꿨다. 깨진 것 자체가 그 두 테스트가 어휘 필터를 실제로 겨누고 있다는 증거다(`.filter(isTopic)`를 떼면 다시 깨진다).

- **재발방지**: **LLM 출력물은 형식 테스트가 통과해도 내용이 틀릴 수 있다는 것을 전제로 다룬다.** 형식 계측기(`parseSummary` 단위 테스트)와 내용 정확도는 서로 독립이며, 전자가 초록불이라는 사실은 후자에 대해 **아무것도 말해주지 않는다.** 이 프로젝트에는 후자를 자동으로 보는 계측기가 없고, 앞으로도 만들기 어렵다.

  그래서 두 가지로 산다:
  1. **입력 가드** — 모델이 밟기 쉬운 함정(발언 주체·찬반·인과·약칭 해석)을 프롬프트에서 명시적으로 막는다. **가드는 보장이 아니라 확률 조정**이다.
  2. **눈 검증을 절차에 넣는다** — 프롬프트나 소스 목록을 고칠 때마다 **실제 기사 몇 건을 원문과 대조**한다. 특히 정치·통계·인용처럼 주체와 수치가 걸린 기사를 골라서 본다. 소량 재실행은 DB 임시 마커로 대상을 좁혀서 하면 비용이 거의 안 든다.

  판정이 실패했다면 다음 계단은 모델 상향(Sonnet 5)이다 — 이번엔 가드만으로 뒤집혔으므로 Haiku를 유지한다.

  성질로는 [T-003](T-003.md)의 형제다. T-003은 "대리 지표(태그 개수)로 만든 검증기가 통과 쪽으로 고장 났다"였고, 이번은 "**형식**이라는 대리 지표가 통과했는데 정작 재고 싶은 것(**내용의 참거짓**)은 아무도 안 봤다"이다. 둘 다 **초록불이 무엇에 대한 초록불인지**를 되묻지 않은 데서 왔다. 새 계측기를 붙일 때 자문할 것: **"이 테스트가 통과하면 내가 실제로 걱정하는 그 일이 안 일어난 것인가?"** 아니라면 걱정거리는 여전히 무방비다.
