# T-006 · Asset.Icon 의 크기는 style 이 아니라 frameShape 로 준다

- **증상**: 빈 상태 아이콘을 `<Asset.Icon name="icon-sunrise-mono" style={{ width: 56, height: 56 }} />` 로 넣었는데 화면에서 눈에 띄게 작았다. 타입 에러도 콘솔 경고도 없다(`style?: CSSProperties` 가 실제로 prop 에 있다). 3개 자리(배너 18px·빈 상태 56px·끝 마감 32px)에 서로 다른 크기를 줬는데 셋 다 똑같이 보이는 것이 유일한 단서였다.

- **원인**: `Asset.Icon` 은 내부적으로 `Asset.Frame` 위에 아이콘을 얹는 구조이고, **프레임의 박스 크기는 `frameShape` 가 결정**한다. 넘긴 `style` 은 프레임이 아니라 안쪽 span 쪽으로 흘러 크기에 영향을 주지 않는다. DOM 실측:

  ```
  DIV  css-1vqadhc  style="width: 24px; height: 24px; background-color: transparent;"   ← 프레임(frameShape 기본값)
   └ SPAN css-xjod4r style="--object-fit: contain; color: …"                            ← 여기에도 내 width 는 없다
      └ svg 24x24
  ```

  즉 **없는 prop 을 넘긴 게 아니라, 있는 prop 이 크기에 안 쓰이는** 경우다. 타입 검사가 못 잡는 이유가 여기 있다.

- **해결**: 크기는 `frameShape={{ width, height }}` 로 주고, 배치(`flexShrink`·`marginTop` 등)가 필요하면 **평범한 래퍼 div** 로 감싼다.

  ```tsx
  <div style={{ flexShrink: 0, marginTop: 1 }}>
    <Asset.Icon name={icon} color={adaptive.grey600} frameShape={{ width: 18, height: 18 }} />
  </div>
  ```

  프레임 배경은 `backgroundColor: transparent` 가 기본이라(`Asset.Frame` 문서의 `adaptive.grey100` 기본값과 달리) 회색 상자가 따라붙지 않는다. 고친 뒤 실측: 프레임 `56x56` / svg `56x56`, 좌우 `131..187`(뷰포트 318 기준 정중앙).

- **재발방지**: **TDS 컴포넌트의 크기는 d.ts 에 `style` 이 있다는 이유로 `style` 로 주지 않는다** — 렌더 결과를 DOM 으로 재서 확인한다. 판별법이 값싸다: 크기를 다르게 준 자리 둘이 **같은 크기로 나오면** 그 prop 은 안 먹고 있는 것이다. 이 건은 스크린샷을 눈으로만 봤으면 "좀 작네" 로 넘어갔을 것이고, `getBoundingClientRect()` 로 수치를 뽑아서야 확정됐다 — 글로벌 CLAUDE.md 「판정에 필요한 수치를 먼저 뽑고 스크린샷은 나중에」의 사례다.
